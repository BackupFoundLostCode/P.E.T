# P.E.T (Stands for Pen, Eraser, and Thief)
My first attempt at C++.
The idea was to search a PC for a file and then copy it to a USB stick.

I have no idea why, but the program is currently doing what it's supposed to do. I haven't really changed much, but it seems to be working now, so I consider the program complete. Maybe there will be some enhancements in the future, but that's it for now. If anyone has any acknowledgments, improvements, or comments, I would be happy to hear them :)

It is now possible to search through an entire list; simply add it to the “NameList.txt” file. Each entry must be on a separate line.

(The letter of your USB device must be D... or you can change it yourself in the code).
